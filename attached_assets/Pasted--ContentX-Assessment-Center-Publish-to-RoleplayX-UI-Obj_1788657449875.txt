# ContentX Assessment Center + Publish to RoleplayX UI

## Objective

Add a user-facing Assessment workflow to ContentX.

ContentX should behave as the authoring and assessment-package factory.

RoleplayX remains the runtime assessment platform.

Golden path:

```text
Create Assessment
    ↓
Select / generate scenarios
    ↓
Review scenarios
    ↓
Create immutable version
    ↓
Validate
    ↓
Publish to RoleplayX
    ↓
Show publish result
```

Do not expose internal concepts such as SimulationSpec, compiler internals, SHA-256, or runtime adapters in the primary UX.

---

Add an Assessment entry to the existing ContentX navigation.

Suggested route:

```text
/assessments
```

Create:


---

# 6. Validate

Button:

```text
[Validate]
```

Call:

```http
POST /v1/assessments/:id/versions/:version/validate
```

Display:

```text
✓ Package valid

3 scenarios
5 competencies
12 evaluation dimensions
```

For failures:

```text
Cannot publish

Scenario 2
Persona is missing a required field.

Scenario 3
Evaluation weights must total 10.
```

Errors must be actionable.

```text

```


---

# 10. UX restrictions

Do NOT:

* create a second scenario editor specifically for RoleplayX
* expose raw package JSON as the primary workflow
* allow editing a published version
* allow publish before validation
* show technical compiler terminology in the main UX
* duplicate existing Scenario editing components

ContentX remains the authoring system.

RoleplayX remains the execution system.
