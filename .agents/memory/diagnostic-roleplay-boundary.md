---
name: Diagnostic roleplay responsibility boundary
description: User-defined responsibilities for ContentX authoring versus RoleplayBot runtime behavior.
---

ContentX writes and exports diagnostic roleplay content and disclosure rules. RoleplayBot presents cues during conversation, records their delivery, and evaluates participant behavior.

**Why:** The user's diagnostic roleplay brief explicitly separates authoring from execution and allows export-only verification when the receiver's code or runtime is unavailable.

**How to apply:** Never assume the repository's RoleplayX integration is an identical RoleplayBot contract. Confirm the receiver's supported version/extension points, preserve existing exports, and report ContentX verification separately from external execution verification.
